## 掉血判定

以下是根据反应式治疗、避免过量治疗的原则制定的初始工程参数，不是社区统一规定。百分比点位只有8位红色通道，边界存在约0.4个百分点的量化误差。

| 单体血量 | 分类 | 处理 |
|---|---|---|
| <20% | 危急 | 达到群疗条件且美德可执行时先美德，否则立即抢救；圣疗手动使用 |
| 20%～<60% | 大掉血 | 即时技能优先；需要普通读条时用圣光术 |
| 60%～<75% | 普通掉血 | 即时技能优先；需要普通读条时用圣光术 |
| 75%～<85% | 普通掉血 | 即时技能优先；需要普通读条时用圣光闪现 |
| ≥85% | 轻微掉血／满血 | 不主动补单体治疗 |

小队：至少3人低于70%，或至少3人低于50%，是群体大掉血。至少3人低于85%是普通群体掉血，可以启动美德。

团队（2026-10-18）：群疗固定至少4人，不再按团队总人数提高门槛。至少4人低于85%为普通群伤；至少4人低于70%或至少4人低于50%为严重群体压力。鸣钟、翅膀和美德的具体血量及后续条件见下文；小队仍为原来的3人规则。

空位、离线、死亡／鬼魂不计入N；未知血量不当作满血或零血。可读存活成员占可读存活＋未知成员不足75%时，不依据队伍血量启动群体策略。团队新增逐人治疗距离检查，只有确认可治疗的在线存活伤员参与团队群疗人数与缺口统计；未知状态不授权治疗。成员之间距离仍未知，不能保证鸣钟／美德覆盖全部受伤者。小队距离与统计逻辑保持原样。

阈值保存在运行程序目录的 `profiles/holy.json` 中的 `HolyThresholds`。关闭程序后修改，再启动；比例写0～1的小数。例如 `HealBelow=0.85`、`Major=0.60`、`GroupLow=0.70`、`GroupCritical=0.50`、`RaidLowFraction=0.30`、`RaidCriticalFraction=0.20`（这两个团队比例字段仅兼容旧配置，不再决定团队群疗人数）、`MinimumCoverage=0.75`、`HolyLightMana=0.30`。自身7／8／9宏与当前目标治疗共用HealBelow，默认均为低于85%；普通自疗还需不抢占更低血量的可治疗队友；自身普通闪现还必须在75%～<85%区间并要求静止，且可通过小队选人或当前团队友方目标施放的可用震击必须先使用，不能被自身普通闪现抢占。治疗石药水仍固定40%，普通圣佑术低于60%；小队和团队牺牲联动圣佑均不受血量限制。HolyLightMana仅保留旧配置兼容，不再限制普通读条圣光术；两种读条治疗均以技能实际可用判断法力是否足够。圣疗与自律检查已移出自动策略，交给玩家手动处理。

### 美德与常规治疗

2026-10-18：小队美德、普通／严重／紧急鸣钟、群伤翅膀及光环掌握保持最低3人；团队这些群疗分支统一至少4人，不再按团队人数比例提高门槛。群疗优先美德起手，包含达到相应人数门槛的多人危急，以及达到普通群疗人数门槛且有人危急的情况。团队至少4人低于20%时才能进入紧急群疗，不保留3人例外。美德冷却、未学、不可用、状态未知或没有可执行后续治疗时，直接继续判断鸣钟、翅膀、光环掌握或单体治疗，不等待美德。每次可施法时重新检查伤情，恢复到不足群疗人数后不继续追加群疗（小队3人、团队4人）。危急群疗中，美德优先于直接抢救、紧急鸣钟／光环掌握及免费治疗；没有当前可用的美德目标时，不为美德额外切人等待，直接继续抢救。非危急时神圣意志临期的单体免费消耗沿用原优先级。

美德接收者与后续直接治疗接收者可以不同：自己满血而队友需要治疗时，只要有已确认可执行的后续治疗，仍可在自己身上铺美德，再按伤情选择治疗对象。后续可执行性必须对应现有治疗优先级实际会治疗／选择的对象，不能借用另一人的可用技能。例如自己80%、优先治疗队友70%、只有闪现可用而圣光术不可用时，小队和团队均跳过美德；圣光术确认可用后才允许铺美德并继续治疗该队友。当前目标尚未切到优先对象时，也按下一位实际治疗对象判断。选人、目标确认及灌注瞬发闪现规则保持不变。确认当前目标就是玩家时，自己的治疗距离由单位身份证明，不依赖可能返回未知的友方距离查询。上述安排不代表工具已确认每人的道标状态。

小队美德按点29从“就绪”变为“冷却”的有效采样启动9秒推定窗口，手动释放也可观察；每帧冷却不会续期，发送按键不会启动计时。首次采样已经冷却、冷却未知或失去连续采样时，不猜测释放时间。窗口自然结束、冷却恢复就绪、脱战、离队、转团队、队伍变化、换窗口、暂停或重启执行时清理。窗口中仍按伤情选人，确认神性之手存在且对象低于治疗线时允许瞬发圣光术，不必等到60%以下；两充能震击和灌注闪仍排在它前面。该窗口不识别每个人的道标归属，也不作为翅膀Buff证据。团队新增独立的同规则9秒窗口，团队与小队窗口互不继承。美德满足条件时先起手，不满足时普通治疗和鸣钟不等待美德；缺少窗口证据时回到原治疗条件。

自身和队友共用常规技能优先级（自身低于20%的直接抢救例外：可用的荣耀／永恒之火优先），自身宏改变施法按键：先判断免费／5圣能消耗及符合原条件的群体冷却，鸣钟前仍先消耗3～4圣能；随后两充能震击 → 灌注闪 → 大掉血时的神性之手瞬发圣光术 → 一充能震击 → 普通3～4圣能消耗 → 移动中无其他瞬发时的神性之手圣光术兜底 → 站定治疗兜底（75%～<85%闪现，其他需要治疗的血量用圣光术）。已选中可治疗对象时，危急分支的两充能震击也先于灌注闪；没有自身震击目标时，自身急救宏可直接救命，不等待切目标。普通自身震击如需选人，仍保留两次目标确认；团队使用上述插件快捷键自动选人，同样等待两次新目标确认。

神性之手在对象低于Major（默认60%，包含危急）、确认Buff临期或当前队伍模式的美德推定窗口中使用，仍要求对象确实低于治疗线、Buff存在且圣光术可用。其他普通缺血不提前消耗Buff；如果走到最终兜底且血量位于闪现读条区间外，站定圣光术仍可能消耗神性之手。临期色块代码已预留，默认未启用：配置 `SpecialPoints.holy_hand.HandExpiryMode=true` 后，黑色=无Buff，匹配非黑ReferenceColor=有Buff且临期，其他非黑色=有Buff未临期；待提供可靠色块后再启用。旧配置不自动启用，也不把旧有无参考色当临期色。原生点94明确无Buff时优先于外部颜色；施法后重新采样，不计固定次数。未知光环不能授权移动读条。仅有被保留的神性之手、无其他可执行后续治疗时，不开启美德。

2026-10-23：仅修改普通读条兜底的技能选择，小队／团队、自身／队友规则一致。血量75%～<85%时使用圣光闪现，区间外仍有治疗需求时使用圣光术；默认治疗线仍为85%，达到治疗线不主动补血。灌注瞬发闪现的血量条件及优先级不变，低血量、危急和移动时仍可按原规则使用。两种普通读条均要求站定、已学、就绪且实际可用；对应技能不可用时等待，不跨区间改用另一种读条。圣光术不再要求低于60%、法力至少30%、明确无灌注或震击冷却；可执行的震击、灌注闪及其他优先治疗仍排在读条兜底之前。神性之手的高优先级与移动瞬发分支不变。已学／冷却／可用未知只跳过依赖它的技能；施法／GCD未知仍暂停普通施法。

冷却与充能采集规则未改变：计时对象缺失时只以公开isEnabled／isActive确认冷却；缺字段、受限或报错保持未知。震击有充能数据时按实际剩余充能判断，正常nil可回退普通冷却，报错不能假定就绪。GetUnitSpeed仍直接交给原生StatusBar显示，普通读条依赖静止点10，确认瞬发的技能不依赖它。

### 可配置参数

关闭程序后修改运行目录 `profiles/holy.json` 的 `HolyThresholds`，再启动；旧文件缺少新增字段时采用默认值。比例使用0～1小数，观察时间使用秒。

| 字段 | 默认值 | 含义 |
|---|---|---|
| Critical | 0.20 | 危急直接抢救及多人危急例外 |
| HealBelow / TollCritical | 0.85 / 0.60 | 鸣钟普通伤员线／大掉血线（小队3人、团队4人）；普通分支另需总缺血≥40个百分点、两次采样 |
| TollLow | 0.80 | 兼容旧配置保留；不再作为小队鸣钟触发线 |
| CooldownReviewSeconds | 2.0 | 伤情趋势采样周期（旧字段名），允许0.5～10秒；不阻挡美德或冷却释放 |
| AutoWings | true | 是否自动使用翅膀 |
| RaidAutoWings | true | 团本是否允许自动翅膀，false为团队安排保留 |
| AutoAuraMastery | true | 是否自动使用光环掌握 |
| AuraMasteryHasToll | false | 玩家确认当前天赋含光环掌握附带鸣钟；换天赋须同步修改 |
| RaidAutoAuraMastery | true | 团本是否允许自动光环掌握；界面开关控制，关闭交给玩家手动释放 |

团本翅膀需AutoWings和RaidAutoWings均为true；光环掌握需自动开关及天赋确认均为true，团本另需团本开关。未点附带鸣钟时保持手动。真实Buff观察仍留待后续单独配置，本轮无需重新取点。

## 点位、光环与首次启用

插件上行1～50为神圣专用字段；11采集牺牲祝福冷却（专用颜色），13复用原空槽判断神圣震击至少2充能，14／15／18为三个物品距离诊断槽；51～90共享成员血量，小队是自己、party1～4，团队是raid1～40。91／92是圣能≥3／5，93是灌注Buff有无，94是神性之手Buff有无，95是当前目标双短距物品确认结果，96确认神圣采集代码已加载；97／98是盾击已学且就绪／可用，99是当前目标审判距离，100确认简化灌注的新采集器已加载。新字段复用预留槽，坐标和总点数不变；旧物品诊断槽黑色会标记“旧采集器或未显示”。100未确认时不执行，避免把旧版94的灌注层数误认成瞬发圣光术Buff。治疗使用点22判断震击是否≥1充能，点13判断是否≥2充能以安排震击优先级；常规盾击要求点13明确为是（震击至少2充能），确认神圣意志临期时豁免；两者由同一次充能采样交给原生阈值控件显示，不在Lua比较秘密数值。充能数据为nil时，治疗仍可使用冷却兜底，但点13为否，不能推断出2充能；接口报错／未知时点13为未知，不启用两充能震击优先分支。13复用原空槽，坐标和总点数不变。

灌注主动触发Buff ID是54149，53576是天赋被动，不能拿被动是否已学推断Buff存在。灌注和神性之手均只检查Buff是否存在，不读取层数。血量／充能／圣能秘密数值只交给原生显示控件。查询前先确认该光环接口可读；受限时显示橙色未知，不把受限查询的nil当成Buff缺失。神性之手使用414273；不再查询自律或圣疗的冷却与可用状态，原生18仅记录物品距离；30／40改为圣佑术498的已学且就绪／可用状态，不新增或移动点位。

外部窗口现在为三个固定点：101灌注Buff、104神性之手、105神圣意志。102美德治疗窗口与103复仇之怒BUFF已删除，其余编号不变。神圣意志点105的配置键是holy_purpose，必须单独取点／取色；不借用原生盾击距离点95，也不从已学天赋推断触发。接口可读时，灌注／神性之手自动使用接口点；受限时才使用配置的外部点。旧翅膀BUFF、美德窗口、自律点与旧2／3层点在加载时移除，剩余点按配置名称保留坐标和参考色。“灌注至少1层”点按同等的Buff有无保留，绝不拿旧层数点代替神性之手。旧配置仍可加载，未设置神圣意志时其状态为未知。外部显示编号105与选人动作编号105属于不同编号空间，不会把神圣意志当作party4。

神圣意志临期优先消耗：有可治疗对象低于HealBelow（默认85%）时，免费荣耀圣令／永恒之火排在美德铺垫、普通鸣钟、震击及灌注闪之前；小队沿用伤情与职责选人并等待两次目标确认，团队通过插件快捷键选人并确认，自身使用原有自身宏。临期且全队在线存活成员达到治疗线、无未知血量时，允许在任意圣能及震击充能状态下盾击。有人掉血但无法治疗时不会转为安全盾击；技能不可用时继续原有治疗判断。治疗石／药水、圣佑、符合条件的危急美德起手及多人危急救场仍优先；不抢断施法、不绕过GCD、距离和技能可用性。施放后重新采样，不按发送按键假定Buff已消耗或圣能已减少。

神圣意志105默认使用临期颜色规则，没有模式开关：黑色=无Buff，匹配非黑参考色=有Buff且临期，其他非黑色=有Buff未临期。重启更新后的外部程序，于Buff临近结束时取该固定点的非黑临期颜色并保存。固定状态源建议设置剩余≤3秒时变为该颜色，阈值在状态源调整；外部程序只读颜色，不从首次看到Buff开始推算秒数。普通有Buff与临期必须使用不同颜色，无Buff必须纯黑。旧配置保留坐标与参考色，旧PurposeExpiryMode字段无论true或false均忽略；若之前采集的是普通存在色，需要重新采集临期色。未配置或停用105点时仍为未知，不授权免费消耗。神性之手的HandExpiryMode规则不变。

诊断105显示神圣意志有无及临期状态；自动日志记录独立状态变化，并在盾击条件中说明是否使用临期例外，不再将被豁免的圣能／充能条件误报为阻挡。状态不变不重复写入。

美德施放要求达到群疗人数门槛并存在可执行的后续治疗；有人危急不再排除美德。小队窗口使用上述冷却变化加9秒计时推定，不需要恢复美德外部点；不采集自己或他人的道标Buff，不将整段冷却都当成窗口。

外部点必须来自位置固定的状态指示区：原有模式为纯黑=否、匹配非黑参考色=是、其他色=未知；神圣意志默认使用三态规则，神性之手则需明确启用其临期模式后使用三态规则：黑=无Buff、匹配非黑临期参考色=存在且临期、其他非黑色=存在但未临期。临期模式只能用于满足该颜色约定的固定状态指示区。移动的默认Buff列表、会变灰的冷却图标和数字抗锯齿边缘不能提供稳定判断。没有可靠外部状态源时，跳过依赖灌注的瞬发闪现，以及依赖神性之手的瞬发圣光术，继续判断已确认可用的震击、荣耀及静止读条治疗；移动时不会把未知Buff当作瞬发。

小队鸣钟日志记录当前伤情分支、是否等待第二次采样、就绪／目标／GCD／资源阻挡及伤员数、总缺血证据；美德日志记录推定窗口开始、结束与清理；神性之手记录有无及临期状态。均写入同一份 `captures/holy-shield-*.log.txt`，状态不变不重复，同一分支内的血量波动和倒计时不触发刷屏；导出快照保留最新证据。界面状态行显示美德推定剩余秒数。
