# 惩戒骑士配置与验证

针对本次攻略天赋的圣殿／自动十字军构筑，暂不考虑套装。Lua采集状态，外部工具每次选择一个动作。翅膀＋处决由军官标记请求；灰烬、鸣钟自动；圣光之锤根据常规／免费机会自动释放。60秒／30秒是规划节奏，程序使用实际冷却而不按固定计时强行施放。

## 启动与取点

1. 更新插件后在游戏执行 `/reload`，启动 `bin/Release/net9.0-windows/RotationUS.exe`，先保持执行关闭。
2. 游戏 `/hiji locate on`，工具选择游戏窗口、点击“定位测试”；通过203/203后游戏 `/hiji locate off`，工具退出定位测试，确认“圣骑士 · 惩戒”和正常心跳。
3. 按下面的七点表配置固定光环显示，逐行取点／取色并保存，核对诊断表中消失、存在及条件色。程序不创建光环显示；位置不能随图标补位移动，消失背景必须纯黑。
4. 按键绑定和两种圣光之锤形态手动验证通过后，用“开启执行”或中键启停。窗口失焦、失去心跳、专精切换均停止发伤害键；手动按键让出500ms。

配置独立保存为程序目录 `profiles/cjq.json`，不会借用奶骑／武器点位。未配置为未知，相关优先级会显示等待原因；窗口或布局变化后重新取点。执行关闭时仍可查看当前候选和阻挡原因。

## 七个特殊点

| 点 | 参考色采集状态 | 黑色 | 其他非黑色 |
| --- | --- | --- | --- |
| 战争艺术 | 两层 | 缺失 | 非参考色表示不足两层 |
| 天穹之遗 | 存在，只判断有无 | 缺失 | 存在 |
| 免费圣光之锤 | 免费机会剩余≤3秒 | 缺失 | 非参考色表示尚未临期 |
| 无可争议的统治 | 存在，只判断有无 | 缺失 | 存在 |
| 复仇之怒 | 剩余≤3秒 | 缺失 | 非参考色表示尚未临期 |
| 当前目标处决 | 自身施加、剩余≤3秒 | 缺失 | 非参考色表示尚未临期 |
| 当前目标灼烧 | 自身施加、存在 | 缺失 | 存在 |

比较精确RGB。指定色表示对应层数／临期条件，不能对着始终同色的图标采样来区分时间。目标减益必须跟随当前目标更新；层数和剩余时间由你配置的固定显示提供，不读取图标数字或猜测。未学天穹之遗、战争艺术、圣光救赎时，对应判断按真实已学状态跳过。

## 标记与输出规则

沿用武器战的小地图追踪“战场军官”与“餐饮供应商”开关。Shift+0、Shift+-沿用现有清除相应追踪的宏，确认宏只负责清标记，不施放技能。开启执行前的旧军官请求会先清除；请在执行已开启后重新请求爆发。

军官请求到达时，已学的翅膀／处决须都自身就绪；否则清理请求。Holy Flames已学且目标没有灼烧时先补公正之剑，然后翅膀→处决，各自进入真实自身CD才确认；两项完成后清理军官。发键后2秒未确认或整组超过8秒会取消。手动关标记、换目标、失去目标、脱战、停机、切窗口、心跳失效都会撤销旧请求。

食物请求：目标处于可打断读条且责难可用、在范围内时Shift+3；明确不满足就清理食物，状态未知则等待。责难和自救物品不等伤害GCD。物品在战斗、存活未骑乘且血量≤40%时按治疗石→治疗药水选择，可在空目标时自救。自身血量<60%且技能就绪可用时先圣佑术（9）；血量<80%先瞬发圣光闪现（8），明确不可用时再荣耀圣令（7）。两种治疗都需GCD就绪且未读条，圣佑术不等GCD。普通读条闪现不自动使用。等于60%／80%不触发对应阈值。其他辅助、防御、祝福只留手动键位。

伤害顺序：当前授权的翅膀／处决 → 常规锤 → 符合消耗条件的免费锤 → 满圣能终结技 → 灰烬 → 鸣钟 → 战争艺术两层公正之剑 → 普通终结技 → 公正之剑 → 审判技能族。免费锤在自身临期、翅膀／处决临期，或没有统治增益且不需等待当前授权翅膀时使用；无军官请求时不会永久等翅膀。

单体用最终审判；附近至少2个有效敌人用神圣风暴，天穹之遗存在时改最终审判。两处分支（满圣能／普通消耗）使用同一规则。不按主动十字军打击。附近人数来自姓名板范围估算，不等于实际命中数；自中心技能范围接口无值时以5码物品范围保守判断。

## 游戏内待验证

版本和角色天赋按你的要求留到实测：确认已导入攻略码、圣殿与自动十字军已学、没有光辉荣耀。核对常规／免费圣光之锤替换、审判替换、实际冷却、七个固定点、技能可用／范围，以及责难可打断状态。未知字段保持橙色并显示等待，不会伪造成功。

先在关闭执行时验证采样，再用木桩核对1／2目标、圣能满值、免费消耗后的真实资源、军官成组、食物责难和物品。切目标／窗口、停止执行再恢复时确认旧爆发不会补放。保存截图与日志可定位等待的字段。

## 离线验证

`dotnet build -c Release`、`--self-test`、`--ui-ret-smoke <PNG路径>`；`uv run --with lupa python Diagnostics/verify_retribution.py E:/MyWork/HijiAddon`。这些测试使用合成像素和模拟游戏API，不发送游戏按键，也不能替代游戏实测。


### 自救键位更新（2026-10-15）

荣耀圣令移到7，圣光闪现移到8，圣佑术移到9；原Shift+'、Shift+反斜杠、Shift+1留空。优先级保留≤40%治疗石／药水，然后<60%圣佑术，最后<80%瞬发闪现→明确不满足时荣耀圣令。战斗中存活未骑乘即可，空敌对目标也能自救，不依赖七个输出特殊点。

7绑定 `/cast [@player] 荣耀圣令`，8绑定 `/cast [@player] 圣光闪现`，9放当前天赋实际圣佑术按钮。荣耀圣令按实际可用性判断资源，不硬编码必须3圣能。七个特殊点无需新增或重取。

瞬发判定采集实际替换技能的C_Spell.GetSpellInfo(...).castTime，仅公开数值为0才允许8；缺失／受限显示未知，不发读条闪现。游戏测试检查B27在获得、消耗瞬发效果时正确变化，API若未反映瞬发效果，需据实调整来源，不能把普通可用状态当作瞬发。
