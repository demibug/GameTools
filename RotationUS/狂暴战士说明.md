# 狂暴战士配置与验收

适用于本次定制的无套装、狐人、山丘领主狂暴战（专精 72）。插件负责采集，RotationUS 负责排序。两端必须一起更新，使用默认诊断窗口；`--legacy` 仍是原防战入口。

用户已确认单体爆发输出恢复正常，专项排查日志、游戏内狂暴诊断输出和狂暴专项测试已清理。其他实际 Buff 来源及木桩／副本场景仍按原验收范围核对。默认雷霆模式为 `presence-only`（仅有无）。鲁莽按用户确认的 **12 秒**纯计时。

## 启动和逐点配置

1. 更新插件后在游戏输入 `/reload`，启动 `bin/Release/net9.0-windows/RotationUS.exe`，保持执行关闭。
2. 输入 `/hiji locate on`，外部选择正确的游戏窗口，点击“定位测试”，等待连续两次一致及 `103/103`。然后输入 `/hiji locate off`，外部退出定位测试，确认“战士 · 狂暴”和动态心跳。
3. 把各 Buff 固定在下面的黑底 Buff 区。显示消失后必须露出纯黑，其他 Buff 不能补位。取点避开层数字边缘、闪光和冷却扫过。
4. 设置区直接显示激怒、雷霆轰击、劈斩、旋风斩、天神下凡五行。显示相应状态后，在对应行点“取点 / 取色”，选取像素，再点本行“保存”。每行独立保存位置和参考 RGB，保存一行不会修改其他行，也不会清除其他行尚未保存的取色。
5. 激怒在临近结束时取非黑参考色，天神下凡在不足 2 秒时取非黑参考色。其余三个点也保存采集颜色，但判断时只区分纯黑／非黑，不与参考色比较。
6. 保存后在表格逐项核对存在、消失及时间颜色，再开启执行。修改或停用点、切换专精、定位、导出都会关闭执行。

| 用途键 | 用途与配置要求 |
| --- | --- |
| `enrage` | 激怒：纯黑缺失；精确等于参考 RGB 为临近结束；其他非黑为正常存在。必须配置时间颜色。 |
| `thunder` | 雷霆轰击有无。普通图标的非黑像素只能代表存在。 |
| `hack` | 劈斩（Hack and Slash）的实际 Buff 有无；不要用天赋图标代替。 |
| `whirlwind` | 旋风斩顺劈增益有无；只观测增益，不自动施放旋风斩。 |
| `avatar` | 天神下凡：纯黑缺失；精确等于参考 RGB 表示不足 2 秒；其他非黑表示正常存在。新配置必须采集不足 2 秒颜色。 |

配置保存在程序目录 `profiles/kbz.json`，重启自动读取。防战和复仇的原单点、参考色独立保存。分辨率、UI 缩放或 Buff 位置变化后重新定位／取点；仅已知末端标记右移且标准点和客户区不变时保留点位。

## 黑底与定位协议

以下坐标是插件 UI 单位，不能直接代替截图客户区像素；实际位置由定位器按缩放计算。

| 区域 | 所有职业、专精统一右侧布局 `wide-v2` |
| --- | --- |
| 标准普通点／进度条 | 原两行各 50 点，位置不变 |
| 附加黑底 | x=530，y=0，宽 200，高 20 |
| Buff 摆放区 | x=530–730，宽 200，整个附加黑底 |
| 黑底外侧空白间隔 | x=730–740，宽 10 |
| 状态／职业／心跳标记 | x=740／750／760，各宽 10，均在黑底外 |
| 右侧余量 | x=770–780，宽 10 |

所有职业和专精使用这套宽版黑底，切换职业、专精、天赋及进入定位模式时恢复同一套位置和尺寸；未接入执行的专精也使用相同背景和标记。Buff 显示连同动画都应留在黑底内，不遮挡外侧标记。外部只接受 `wide-v2` 定位；旧 `legacy` 和 `wide-v1` 坐标不能用于执行，出现多套有效候选仍拒绝定位。旧专精配置载入新共享布局时，特殊点及参考色停用，须重新取点、取色。已在 `wide-v2` 且客户区、标准点一致的配置继续保留。更新后 `/reload`、重启外部工具并重新定位，保存坐标后仍需真实心跳变化才能执行。

食物标记开启、近战条件成立、目标正在施法／引导且拳击就绪时打断；脱战、目标停读条、拳击冷却或离开近战时取消食物标记。军官标记请求鲁莽，随后请求独立天神；只有一个就绪就先用它。脱战或两者确认进入自身冷却后取消军官，GCD 和已发送按键都不算施放成功。

碎裂投掷要求 15 码综合条件、目标有吸收且就绪，两专精均启用。英勇投掷沿用内置建议与 15 码条件；不能绕过尚未确定的高优先级输出。狂暴天神无需等待雷霆一击冷却，防战继续保留这个条件。没有旋风斩自动按键。

## 状态来源与降级

| 状态 | 默认来源 | 可选来源／限制 |
| --- | --- | --- |
| 激怒 | 固定点三态 | 不按固定秒数猜临近结束。 |
| 天神 | 固定点 | 时间颜色未配时，只禁用“不足 2 秒”提前条目，缺失不等于即将结束。 |
| 鲁莽 | 插件成功施法计时 | 玩家 `UNIT_SPELLCAST_SUCCEEDED` 1719 开始 12 秒，发送键或失败施法不会启动；无记录／到期即不存在。 |
| 雷霆层数 | 仅有无固定点 | 精确模式仅使用经过验证的接口条，不增加第六个特殊点。接口权限失败会回退固定点；只有存在性已知才可明确降级成仅有无。 |
| Hack and Slash／旋风斩增益 | 固定点 | 经游戏内验证的实际光环 ID 可启用接口查询。失败则回退固定点，未配点是未知。 |
| 技能形态／可用／冷却 | 技能 API | 动态查询替换 ID，不用指南的天赋 ID 冒充施法或光环 ID。 |
| 怒击充能 | 进度条 B1/B2 | 实际形态无充能对象时再查基础技能；有效位缺失时不能读取旧条。 |
| 怒气 >100 | 原生状态条覆盖 F7，范围 100–101 | 原始整数怒气直接传给允许 Secret 的 SetValue；100 为黑，101 为白，不比较 8 位比例或最大怒气。 |
| 目标吸收 | 原生状态条覆盖 F10，范围 0–1 | 吸收整数直接传给 SetValue；0 为黑，至少 1 为白，失败仍为橙色未知。 |
| 敌人数 | 可见敌对姓名板及距离估算 | 不是实际命中数；距离/API 失败为未知。 |

仅有无模式只删除单体爆发的“两层提前”条件，保留天神临近结束提前和普通雷霆轰击位置。切为精确模式后，若两层来源未知而存在性已知，原因中显示“已降级”；不能把一层当两层。普通雷霆一击不会在技能已经强化为雷霆轰击时冒充基础技能使用。

高优先级条件未知时等待，并显示具体条目；已确认不可用的技能不因无关 Buff 未知阻塞后续。已确定的保命、标记爆发仍能先处理。标准布尔点纯白为是、纯黑为否、其他颜色为未知；采集失败输出橙色，不能解释成无 Buff 或零层。

鲁莽始终按时间，不恢复登录／重载前状态，不查询实际光环来延长计时。死亡、角色／专精或天赋方案改变清理计时；外部重连直接读插件计时。角色只保存时长参数，不保存成功时刻。装备／天赋改变后需要重新核对后续施法的时长。

## 参数设置命令

设置鲁莽计时时长，游戏输入：

```text
/hiji fury duration 12
```

`duration` 保存角色参数并清空当前计时，后续成功施法按该时长计算。

只有实际游戏中已确认的光环 ID 才使用下列可选命令（ID 用真实数字替换）：

```text
/hiji fury aura thunder ID
/hiji fury aura hack ID
/hiji fury aura whirlwind ID
```

传 0 停用。光环 ID 设置只在当前插件会话有效，重载后回到固定点方案，避免未经复核的 ID 自动开启。雷霆轰击天赋 435607、Hack and Slash 天赋 383877 不直接当实际光环 ID 使用。当前未在游戏内证明接口两层可读，默认不启用精确接口。

## 导出和实际验收

“保存截图与日志”同时保存原始 PNG、字段 CSV、日志和布局 JSON。CSV 包含点名、客户区坐标、原始 RGB、来源／状态；雷霆行含配置模式，决策原因含实际降级模式。启用点包含在同一次截图范围里，越界会拒绝配置。

先在执行关闭时核对：激怒黑／正常／结束色；天神有／无／结束色；雷霆 0／1／2；两个增益存在／缺失；怒气 100／101；姓名板 2／3、6／7；剩一充能；GCD 与自身冷却；手动鲁莽开始／12 秒结束／失败按键。记录真实 Buff ID 与失败原因。

随后分别验收四个输出分支、军官双爆发及仅一个就绪、只天神爆发、目标吸收、距离边界、手动让出、前后台切换、专精切换、缩放后重新定位。木桩和副本分开留截图／日志，特别检查副本权限及姓名板估算变化。没有实际日志的场景仍为未验收。
